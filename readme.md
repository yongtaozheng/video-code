# 前端也能这么有趣

一个收集前端创意效果与交互实验的项目，包含 3D 展示、UI 组件、动画特效、图片与 SVG、轮播图和音频可视化等示例，主要使用 HTML、CSS 和 JavaScript 实现。

适合用来学习效果实现、寻找交互灵感，也可以作为视频演示和创意练习的参考。

## 项目目录

```text
video-code/
├── 3D/              # 3D 展示与空间特效
├── UI组件/          # 加载动画、按钮、输入框、登录面板等
├── 交互效果/        # 拖拽、鼠标交互、页面转场等
├── 动画特效/        # 粒子、天气、流光等动画
├── 图片和SVG/       # 图片处理、卡片展示与 SVG 动画
├── 轮播图/          # 各类轮播切换效果
├── 音频与可视化/    # 音乐播放与音频可视化
├── 演示动画/        # 演示动画素材
├── 其他/            # 趣味实验与实用工具
├── images/          # 公共图片资源
└── temp/            # 临时素材与实验文件
```
