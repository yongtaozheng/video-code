# 山间慢行列车

直接打开 `index.html`，无需安装、联网或构建。Three.js 承载手绘窗景与独立翅膀动画；车厢、全景原画和运行依赖均保存在本目录。

一段 96 秒的持续旅途：窗外的麦田、湖泊和山村缓慢经过，近处树木和草叶以不同速度掠过。没有任务或关卡，旅途会自然继续。

- 点击窗扣或底部「开窗」：玻璃上升，微风带动窗帘、茶汽与浮尘；再次点击关窗。
- 点击旅行本或「翻页」：整张右页沿实际书脊从右向左翻起、弯曲并落下，逐渐露出下一页沿途速写；落页后才更新页码，翻动中连点不会重复触发。
- 点击窗外或「伴飞」：小鸟靠近车窗，伴飞一段后离开；平时也会偶尔飞过。
- 点击茶杯：茶面泛起涟漪，热气逐渐升起并轻轻向指针方向弯曲。
- 声音默认关闭；开启后播放本地合成的列车行进声和风声。空格或暂停按钮冻结所有动画；切换后台冻结时间并静音。减少动态效果偏好下默认暂停，可主动继续。
- 窄屏保留沉浸构图，底部按钮提供不依赖画面热点的操作入口。

`assets/art/` 保存由内置 image_gen 生成的原创车厢与沿途风景原画。`assets/art.js` 是其 data URL 包，确保 file:// 下 Canvas/WebGL 可离线读取。更新图片后运行 `python3 tools/build_art_bundle.py`。

素材提示词：正视的大幅车窗、蜂蜜色橡木车厢、苔绿座椅、旅行本与热茶，精致水彩和水粉绘本质感；配套杏色天空、蓝灰远山、青绿色湖泊、金色麦田和陶瓦山村横向全景。无文字、无标志。
