# 花溪小院

按已确认的梦幻手绘花园画风制作的 Three.js 分层动画。场景由花草、溪流、木屋与小桥构成。约 180 秒完成一次连续花园漫游，没有任务或关卡。

## 打开

直接打开 `index.html`。全部脚本和图像保存在本地，不需要联网、安装依赖或启动构建工具。

## 动画与交互

- 溪流笔触沿河道持续向下游移动，双相位交叉淡化避免循环跳帧；河岸、岩石与植被保持稳定。
- 瀑布水纹向下流落，落水处不断产生水花与扩散波纹。灌溉水滴持续落下。
- 柳叶、紫藤和前景花草随微风摆动；长按空白处或开启微风按钮可以起风，花瓣随风飘落。
- 蝴蝶沿曲线飞行，翅膀在三维中起伏；轻点花田或使用开花按钮，会长出手绘花朵。
- 轻触水面泛起涟漪，镜头缓慢靠近庭院、移向花桥和花田，再回到起点。
- 手机默认从溪畔庭院开始横向漫游，也可手动拖动探索花园。手动控制视角会交回镜头控制权。
- 支持暂停、回到清晨、键盘开花按钮；空格暂停（焦点不在控件时）。时间线可选择不同的花园时刻。
- 声音默认关闭，开启后播放本地合成的溪流底声和稀疏风铃。暂停或切换后台会静音并冻结动画。

## 结构

Three.js 承载手绘贴图、透视图层、局部 UV 动效和翅膀动画网格。当前底图不含水车、齿轮或静态瀑布。水帘使用独立透明 RGBA 图层，完整搬运颜色与透明度；喷溅和泡沫由动态笔触生成，共用同一动画时钟。

- `assets/painted-garden.js`：当前动画运行时。
- `assets/art/garden-plate-v2-dry.png`：已清除静态水帘、水滴和落水泡沫的底图。
- `assets/art/waterfall-v1.png`：独立透明水帘贴图，包含动态水纹的手绘笔触。
- `assets/art/botanicals-v1.png`：蝴蝶/花朵图集。
- `assets/illustrations.js`：使用 data URL 打包的本地图像，保证直接打开文件时 WebGL 贴图可读。
- `tools/build_art_bundle.py`：更新 PNG 后重新生成图像包，不修改图像内容。

依赖 Three.js 0.160.1，MIT 许可证见 `assets/THREE-LICENSE.txt`。
